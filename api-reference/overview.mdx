title: API reference
description: The three real-time integration surfaces exposed by the HGT platform.
---

Hybrid Greentech's platform is reached over MQTT-based, event-driven APIs — one per integration surface. Each is specified with AsyncAPI, and the full channel, message, and schema reference is rendered inside that surface's own tab.

<CardGroup cols={2}>
  <Card title="Delegated Operators" icon="plug" href="/delegated-operators/welcome">
    Third-party dispatch of grid assets: tasks, activations, and telemetry over MQTT, plus a REST layer for discovery and monitoring. Its equipment are **assets**.
  </Card>
  <Card title="Distributed Energy Resources" icon="bolt" href="/distributed-resources/welcome">
    One API for every resource type — EV chargers, heat pumps, batteries, CHP, P2X, PV, and other equipment: registration, telemetry, absolute setpoints, and acknowledgements over MQTT. Its equipment are **resources**.
  </Card>
</CardGroup>

The v1 EV charger and heat pump APIs are deprecated and remain published for existing integrations. See [Migrating to v2](/distributed-resources/migration).

For direct hardware integration (Modbus TCP or IEC104) rather than cloud MQTT/REST, see [OEM Integration](/controller/overview).

See [API Versioning](/api-versioning) for how these specs and the REST layer evolve over time.
